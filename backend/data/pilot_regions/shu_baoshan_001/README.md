# 上海大学宝山校区周边区域资料

资料核对日期：2026-11-11。区域编号：`SHU_BAOSHAN_001`。

包含 6 条道路（上大路、锦秋路、南陈路、汇丰路、聚丰园路、沪太路）、7 个路口、14 条道路—路口连接关系，以及上海大学宝山校区、北门和南陈路出入口 3 处地点资料。

学校与校门地址来自[上海大学访客页面](https://www.shu.edu.cn/fk.htm)和[上海大学保卫处交通提示](https://baoweichu.shu.edu.cn/info/1061/12631.htm)。只使用地址事实，未将报到期间临时停车安排或地铁出入口施工信息作为长期交通规则。

道路和路口来自 [OpenStreetMap API 快照](https://www.openstreetmap.org/api/0.6/map?bbox=121.380,31.305,121.410,31.330)。`source_snapshot/osm_roads.json` 保留所选道路的原始 way ID、节点序列和坐标；完整下载响应和构建脚本保存在 `artifacts/shu_baoshan_20261111/`。

每个路口由两条具名道路的共享 OSM 节点确认。多车道有多个共享节点时，选其中一个真实节点作为近似展示点，保留其余节点用于追溯；未将道路中心点冒充事件位置。坐标为 WGS84，地图数据遵循 ODbL，署名 © OpenStreetMap contributors。

这是校区周边有限范围的公开资料整理，不是行政区划、完整道路 GIS 或现场测绘。POI 只按校方地址关联道路，没有编造校门精确坐标。资料包不包含实时交通、历史事故、处置结果或案例；统计和案例未匹配时应保留为空。

导入使用既有 `/regional/context-packs/import` 接口。文件中的业务 ID 独立于 OSM ID，重复导入保持幂等，不修改其他区域或既有事件。
